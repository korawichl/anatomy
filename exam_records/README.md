# 📁 Anatomy Exam Records & Mistake Tracking System

ระบบบันทึกคะแนนสอบวิชากายวิภาคศาสตร์ (Anatomy Exam Lab) และวิเคราะห์จุดผิดพลาด (Mistake Log & Weak Topics) ซิงค์ตรงกับ Git Repository

---

## 📑 โครงสร้างไฟล์ในโฟลเดอร์นี้

1. **`MISTAKE_LOG.md`**:
   - บันทึกข้อสอบที่ตอบผิดในแต่ละรอบแบบละเอียดยิบ
   - ระบุ: รหัสข้อ, โจทย์, ตัวเลือกที่คุณตอบ (ผิด), ตัวเลือกที่ถูกต้อง
   - คำอธิบายทางการแพทย์และเหตุผลอย่างละเอียด
   - **แหล่งอ้างอิงไฟล์ PDF และเลขหน้าสไลด์ของอาจารย์** เพื่อให้กลับไปอ่านทบทวนได้ตรงจุดทันที

2. **`SCORE_HISTORY.md`**:
   - สรุปตารางคะแนนสอบทุกรอบสะสม
   - สถิติจำนวนครั้งที่สอบ, อัตราความแม่นยำ (Accuracy %), คะแนนเฉลี่ย, คะแนนสูงสุด
   - สรุปแนวโน้มความก้าวหน้า

3. **`WEAK_TOPICS_REPORT.md`**:
   - ชี้เป้าหัวข้อจุดอ่อนที่ต้องทบทวนด่วน (Priority Action Items)
   - จัดกลุ่มตามระดับความแม่นยำ:
     - 🔴 **หัวข้อวิกฤต (< 60% — Needs Urgent Review)** พร้อมเลขหน้าสไลด์
     - 🟡 **หัวข้อที่เริ่มเข้าใจ (60% - 79% — Developing)**
     - 🟢 **หัวข้อที่แม่นยำแล้ว (≥ 80% — Mastered)**

4. **`history.json`**:
   - ฐานข้อมูลดิบ (Raw JSON Array) ของประวัติการสอบทุกรอบ เพื่อให้ระบบหน้าเว็บและ Script ภายนอกนำไปประมวลผลต่อได้

---

## 🚀 วิธีการบันทึกข้อมูลและจุดผิดพลาดขึ้น Git

### วิธีที่ 1: กดบันทึกผ่านหน้าเว็บ (เมื่อเปิดแบบ Local Dev `npm run dev`)
- เมื่อทำข้อสอบเสร็จในหน้าสรุปผลสอบ หรือในหน้าประวัติการสอบ ให้คลิกปุ่ม **"💾 บันทึกลง Git (Save to Git)"**
- ระบบจะทำการประมวลผลข้อมูล แปลงเป็น Markdown และสั่ง Git Commit & Push ให้อัตโนมัติในคลิกเดียว

### วิธีที่ 2: รันผ่านคำสั่ง Terminal
```bash
# เมื่อต้องการสร้างและอัปเดตรายงานทั้งหมดขึ้น Git
npm run record
```
หรือหากต้องการส่งไฟล์ผลสอบ JSON เข้ามาประมวลผล:
```bash
node scripts/record_to_git.cjs path/to/attempt.json
```
