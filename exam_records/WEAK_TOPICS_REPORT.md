# 🎯 รายงานวิเคราะห์หัวข้อจุดอ่อนที่ต้องทบทวนด่วน (Weak Topics Analysis)

> รายงานนี้ประมวลผลจากประวัติการทำข้อสอบจริง เพื่อค้นหาหัวข้อที่มีความแม่นยำต่ำกว่า 60% พร้อมระบุหน้าสไลด์ของอาจารย์ที่ต้องเปิดอ่านซ้ำ

*ยังไม่มีประวัติการสอบที่บันทึก — ระบบจะแสดงหัวข้อที่ต้องทบทวนด่วนแยกตามเกณฑ์ 🔴 <60% 🟡 60-79% 🟢 ≥80%*
