# Anatomy Exam Lab (ระบบเว็บไซต์ฝึกทำข้อสอบกายวิภาคศาสตร์)

ระบบเว็บแอปพลิเคชันสำหรับฝึกทำข้อสอบวิชา **Anatomy (กายวิภาคศาสตร์)** สำหรับนักศึกษาพยาบาลศาสตร์และวิทยาศาสตร์สุขภาพ มหาวิทยาลัยรังสิต (RSU Nurse) พัฒนาด้วย **React 19 + TypeScript + Vite + Tailwind CSS** ออกแบบสถาปัตยกรรมแบบ **Local-first** จัดเก็บข้อมูลในเครื่องของผู้ใช้ ไม่ต้องสมัครสมาชิกหรือพึ่งพา API ภายนอก

---

## 📚 แหล่งข้อมูลและการอ้างอิงเอกสารหลัก (3 เล่ม / 300 ข้อ)

คลังข้อสอบ 300 ข้อถูกสร้างและตรวจสอบอ้างอิงตรงตามสไลด์คำสอนทั้ง 3 ไฟล์:

1. **Cardiovascular and Lymphatic Systems (100 ข้อ)**
   - ไฟล์อ้างอิง: `BNS102-Anatomy of Cardiovascular and Lymphatic Sys_261024_214357.pdf` (102 หน้า)
   - เนื้อหา: เลือด, เซลล์เม็ดเลือด, หัวใจ, ผนังหัวใจ, เยื่อหุ้มหัวใจ, ลิ้นหัวใจ, ระบบนำไฟฟ้า, หลอดเลือดแดง-ดำ, ต่อมน้ำเหลือง, ม้าม, ต่อมไทมัส, ท่อน้ำเหลือง Thoracic duct
2. **Digestive System (100 ข้อ)**
   - ไฟล์อ้างอิง: `Digestive system_Nartnutda_261024_214326.pdf` (68 หน้า)
   - เนื้อหา: ผนังทางเดินอาหาร 4 ชั้น, เยื่อบุช่องท้อง (Peritoneum), ช่องปาก, ฟัน, ต่อมน้ำลาย, หลอดอาหาร, กระเพาะอาหาร, ต่อมกระเพาะ, ลำไส้เล็ก, ลำไส้ใหญ่, ตับ, ถุงน้ำดี, ตับอ่อน
3. **Urinary System (100 ข้อ)**
   - ไฟล์อ้างอิง: `Urinary System-Nartnutda_Nurse RSU_May 2026_261024_214340.pdf` (80 หน้า)
   - เนื้อหา: หน้าที่ของไต, การวางตัว, ชั้นพังผืดหุ้มไต, โครงสร้างภายในไต, หน่วยไต (Nephron), Glomerular filtration, Loop of Henle, Juxtaglomerular Apparatus (JGA), ท่อไต (Ureter), กระเพาะปัสสาวะ, ท่อปัสสาวะ และความแตกต่างระหว่างเพศ

## ✨ ฟังก์ชันและความสามารถหลัก

- **Dashboard:** สรุปสถิติจากประวัติสอบจริง (จำนวนครั้งที่สอบ, คะแนนเฉลี่ย, คะแนนสูงสุด, ความก้าวหน้ารายระบบ, หัวข้อที่ต้องทบทวนเร่งด่วน)
- **Exam Setup:** เลือกสอบรายระบบ หรือ รวมทุกระบบ (All Systems) / เลือกจำนวนข้อ (10, 20, 30, 50, **70 ข้อ**, หรือตามใจชอบ) / เลือกระดับความยาก / เปิด-ปิดตัวจับเวลา
- **โหมดการสอบ 4 รูปแบบ:**
  - `Exam Mode`: โหมดสอบจริง จับเวลา ตรวจเฉลยเมื่อส่งกระดาษคำตอบ
  - `Practice Mode`: เฉลยทันทีทีละข้อพร้อมคำอธิบายภาษาไทยและศัพท์ภาษาอังกฤษ
  - `Review Mode`: ดึงเฉพาะข้อที่เคยตอบผิดในอดีตมาสอบซ้ำ
  - `Random Mode`: สุ่มข้อสอบจากคลัง
- **Exam Room:** ระบบจับเวลา, สลับลำดับข้อและตัวเลือกโดยเฉลยไม่เพี้ยน, แถบ Progress bar, ปุ่มติดธงทบทวน, ตาราง Question Navigator, ป้องกันการสูญหายเมื่อรีเฟรชหน้า (Auto-recovery)
- **ระบบตรวจและเฉลย:** แสดงคะแนน, เปอร์เซ็นต์, เวลาที่ใช้, ผลตรวจรายข้อ, คำอธิบายเฉลยละเอียด พร้อมระบุไฟล์และเลขหน้า PDF ต้นฉบับ
- **Performance Analytics (วิเคราะห์จุดอ่อน):** จัดกลุ่มสถานะหัวข้อย่อยเป็น **Strong (≥80%)**, **Developing (60-79%)**, และ **Needs Review (<60%)** พร้อมปุ่มลัด **Practice Weak Topics**
- **Exam History:** ค้นหา, กรองรายระบบ, เรียงลำดับตามวันที่หรือคะแนน, ดูผลสอบย้อนหลัง, ลบประวัติที่เลือก หรือ ล้างทั้งหมด
- **ระบบส่งออกข้อมูล (Export Data):**
  - **CSV Export:** เข้ารหัส UTF-8 BOM (`\uFEFF`) ภาษาไทยไม่เพี้ยนใน MS Excel
  - **Excel Export (.xlsx):** สร้างไฟล์ Excel 5 ชีตสมบูรณ์ (Summary, Exam History, Answer Details, Weak Topics, Question Bank)

## 🚀 วิธีการเปิดใช้งานเว็บไซต์ (How to Run)

### 1. ติดตั้ง Dependencies (ทำครั้งแรก)
```powershell
npm install
```

### 2. รันโหมด Development (เปิดใน Browser)
```powershell
npm run dev
```
เปิดบราวเซอร์ไปที่: `http://localhost:3000`

### 3. ตรวจสอบและ Build Production
```powershell
npm run build
npm run preview
```
